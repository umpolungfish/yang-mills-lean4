The Wilson stage convergence theorem is audited alongside these declarations in SchwingerConv.lean: stageObservableSchwinger_tendsto_iid proves the full finite-tuple limit, including repeated continuum points, with stage spacing 1/(m+2) and physical side length m+2.

concreteOS4DContinuumTheory is a separate checked OS declaration. The translation-invariance counterexample is recorded by YangMills.concreteOS4D_fails_trans_inv; it is not the Wilson stage limit.
